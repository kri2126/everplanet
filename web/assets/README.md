# web/assets — 그림 에셋 규격서

`web/evergreen-3d.html`은 시작할 때 이 폴더의 `manifest.json`을 읽고, 거기 적힌 이름의 PNG가 있으면 게임 안에서 캔버스로 그리던 그림 대신 그 PNG를 씁니다. PNG가 없거나 깨져 있으면 캔버스 그림으로 되돌아가므로, **파일을 하나씩 바꿔 끼워 가며 바로 확인**할 수 있습니다.

지금 들어 있는 PNG 35장은 게임이 캔버스로 그리던 그림을 그대로 뽑은 **예시**입니다. 같은 이름·같은 비율로 새 그림을 덮어쓰면 됩니다.

## 바꿔 끼우는 법

1. 아래 표의 이름으로 PNG를 만든다 (투명 배경, 표의 픽셀 크기 또는 같은 비율의 더 큰 크기).
2. 이 폴더의 같은 이름 파일을 덮어쓴다.
3. `manifest.json`의 `"version"` 숫자를 1 올린다 (브라우저 캐시를 비우기 위해 — 안 올리면 새로고침해도 옛 그림이 보일 수 있음).
4. 커밋하면 GitHub Pages가 몇 분 안에 반영한다. 로컬에서 보려면 `web/` 폴더에서 `python3 -m http.server 8950` 같은 서버를 띄우고 `http://localhost:8950/evergreen-3d.html`을 연다 (파일을 직접 열면 `fetch`가 막혀 에셋을 못 읽음).

`manifest.json`에서 항목을 지우면 그 그림만 캔버스 그림으로 돌아갑니다. 새 종류의 그림(예: 나무 4번째 종류)을 추가하려면 코드에서 `spriteTex(w, h, draw, '이름')`으로 등록해야 하니 그때는 말해 주세요.

## 공통 규칙

- **PNG, 투명 배경.** 흰 배경 JPG는 안 됩니다.
- **발 자리 = 아래 가운데.** 판은 밑변이 땅에 닿게 서므로, 그림의 맨 아랫줄이 발·기둥 밑동·바닥이어야 합니다. 아래에 여백을 두면 그만큼 떠 보입니다.
- **가로세로 비율을 지킬 것.** 게임 안 판의 크기(유닛)는 코드에 고정되어 있어, 비율이 다른 그림을 넣으면 늘어나거나 눌립니다. 픽셀 수는 표보다 커도 됩니다(2배 권장, 예: 192×256 → 384×512).
- **카메라는 남쪽 위 약 40°에서 북쪽을 봅니다.** 그림은 "정면보다 살짝 위에서 본 모습"으로 — 나무·덤불은 윗면(밝은 면)을 넓게, 아랫면 그늘은 좁게. 캐릭터·NPC는 정면/등/옆 그대로.
- **가장자리는 딱 떨어지게.** 대부분의 판은 알파 50% 기준으로 잘라 그리므로(alphaTest 0.5) 반투명 테두리·부드러운 그림자는 사라집니다. 물·포말·빛 계열(`waterfall`, `foam`, `puff`, `slash`, `sparkle`)만 반투명이 살아납니다.
- **외곽선 2~3px, 어두운 같은 계열 색** (검정 대신 잎은 진초록, 나무는 진갈색). 원작의 셀 느낌입니다.
- **빛은 위·왼쪽에서.** 하이라이트는 왼쪽 위, 그늘은 오른쪽 아래.
- **색은 로드맵 6 §1-2 표**를 기준으로: 풀 `#7ccf3a`, 잎 `#5cc23a`/윤곽 `#2f7a22`, 기둥 `#8a5a2b`, 절벽 `#d9b26f`, 물 `#3fb6f0`, 별 `#4ff0e8`, 텐트 `#3aa8a0`, 슬라임 `#4aa6f5`.
