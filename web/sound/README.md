# web/sound — 효과음

`web/evergreen-3d.html`은 처음 소리를 낼 때 이 폴더의 `manifest.json`을 읽고, 거기 적힌 파일을 불러와 효과음으로 씁니다. 파일이 없거나 깨져 있으면 **같은 소리를 코드로 합성해서** 대신 쓰므로 게임이 조용해지지는 않습니다. 배경 음악은 `web/audio/`에 따로 있습니다.

## 지금 들어 있는 소리

| 이름 | 파일 | 언제 나나 | 출처 |
| --- | --- | --- | --- |
| `step_grass` | `grass/step_grass_01~16.wav` (16개, 각 0.22초, 44.1kHz 모노) | 풀 위를 걸을 때 | 직접 합성(v4C) — `tools/grass_synth.js` |

**풀 위**는 지형에 `tile_grass` 질감이 칠해진 곳입니다. 모래길·돌계단·가파른 바위·물가 바닥·다리·데크·얕은 물·헤엄칠 때·공중에서는 나지 않습니다(그 바닥 소리는 따로 만들 예정). 게임의 `surfaceAt()`이 지형 칠하기와 같은 규칙으로 판정합니다.

## manifest.json 항목

| 키 | 뜻 | 지금 값 |
| --- | --- | --- |
| `volume` | 최종 음량(0~1). 파일은 피크 0.9로 맞춰져 있음 | 0.075 (아주 작게, 살짝 들리는 정도) |
| `every` | 몇 걸음에 한 번 낼지 | 2 |
| `skip` | 낼 차례 중 건너뛸 비율 | 0.25 |
| `maxGap` | 이만큼 걸음 연속으로 조용하면 다음엔 꼭 낸다 | 5 (약 1.3초) |
| `files` | 무작위로 고를 소리 목록 | 16개 |

재생할 때마다 최근 4개와 다른 파일을 고르고, 피치 ±10% · 음량 60~100% · 시작 0~20ms 늦춤을 무작위로 줘서 반복감을 줄입니다.

## 바꿔 끼우는 법

1. 같은 이름의 WAV(또는 OGG/MP3 — `files`의 확장자도 같이 바꿈)로 덮어쓴다. 개수를 바꾸려면 `files` 목록을 고친다.
2. `manifest.json`의 `"version"`을 1 올린다(브라우저 캐시 비우기).
3. 커밋하면 GitHub Pages가 몇 분 안에 반영한다.

## 합성 소리 다시 만들기

`web/sound/tools/`에서 `node make_grass.js` — `grass/` 아래 16개를 다시 씁니다. `tools/` 안의 파일을 고쳐 커밋하면 GitHub Actions(`.github/workflows/make-sound.yml`)가 자동으로 이 스크립트를 돌려 WAV를 다시 만들고 커밋합니다(Actions 탭에서 수동 실행도 가능). 소리 높이는 `make_grass.js`의 `center`(소리 중심 Hz)·`lp`(윗선 Hz)로 조절합니다(지금 4200 / 8500).
