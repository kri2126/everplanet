# 로드맵 1 — 1단계: 이동·환경·카메라 (완료)

**상태: 확정 · 완료**
아스마라 한 행성을 "걸어다니는 감각"만으로 성립시키는 단계. 전투·성장·저장은 의도적으로 전부 제외했습니다.

---

## 1. 이 단계의 목표

원작 에버플래닛의 핵심 감성인 **"작은 행성 위를 걷는다"**를 재현하는 것 하나에 집중했습니다.
전투나 성장 같은 시스템을 붙이기 전에, 아무것도 하지 않고 걷기만 해도 기분이 좋은 상태를 먼저 만드는 게 목표였습니다.

---

## 2. 제작 히스토리 (버전별)

| 버전 | 내용 | 판정 |
| --- | --- | --- |
| Unity 초안 | C# 기획 문서 + 핵심 시스템 스크립트(이동, 전투, 성장, 몬스터 AI, HUD, 저장) 설계 | 웹으로 전환, 스크립트는 `Assets/Scripts/`에 보관 |
| 웹 V1 | 캐릭터 이동(WASD/방향키/터치 조이스틱), 카메라 추적, 맵 경계, 바위·식물 충돌 | 기반 확보 |
| 웹 V2 | 원작 그래픽 자료 조사 반영 — 원형 행성 필드, 치비 캐릭터, 자연 소품, 파스텔 동화풍 배색 | 톤 확정 |
| 웹 V3 | 숲길 경로 구조 + **안개**로 시야 제한 + 3인칭 카메라 오프셋 | **폐기** — 안개는 원작의 느낌이 아니었음 |
| 웹 V4 | 원작 실제 플레이 영상 분석 후 **정구형 투영(sphere projection)**으로 렌더링 전면 재작성. 오픈월드 자유 이동 복귀 | 핵심 메커닉 확정 |
| 웹 V5 | 카메라 틸트 적용 — 완전 탑뷰에서 살짝 기울어진 3인칭 시점으로 | **현재 버전** |

V3에서 V4로 넘어간 판단이 이 프로젝트에서 가장 중요한 분기였습니다.
안개로 시야를 가리는 건 흔한 처리이고 원작의 느낌이 나지 않았습니다. 대신 **플레이어를 가상 구체의 정점에 놓고 거리에 따라 지형을 수축·소실시키는 실제 투영 수식**으로 바꾸면서, 원작 특유의 "둥근 지평선 너머는 걸어가야 드러난다"는 감각이 나왔습니다.

## 3. 확정된 스펙

### 월드 수치

| 상수 | 값 | 설명 |
| --- | --- | --- |
| `PLANET_R` | 520 | 가상 구체의 반지름. 클수록 완만하고 시야가 넓어짐 |
| `HORIZON_D` | 약 804 | 지평선 거리. 이 너머는 보이지 않음 |
| `WORLD_RADIUS` | 1500 | 실제로 걸어다닐 수 있는 전체 범위 |
| `TILT` | 0.62 | 카메라 기울기. 1에 가까울수록 완전 탑뷰 |
| `PLAYER_RADIUS` | 15 | 플레이어 충돌 반경 |
| 이동 속도 | 200/초 | |

한 자리에서 보이는 면적은 행성 전체의 약 29%이고, 그마저 가장자리는 극단적으로 압축되어 보입니다.

### 투영 방식

```
screenDist = PLANET_R × sin(d / PLANET_R)      // 화면상 거리
scale      = cos(d / PLANET_R)                 // 거리에 따른 축소
sy         = sin(angle) × screenDist × TILT    // 카메라 기울기
```

거리 `d`가 `HORIZON_D`를 넘으면 그리지 않습니다(지평선 컬링).

### 배치된 콘텐츠

나무·바위 약 240개, 버섯 16개, 샘물 1개, 장식용 길·울타리·표지판. 전 지역에 균일하게 분포되어 있습니다.

### 조작

PC는 WASD/방향키, 모바일은 화면 하단 가상 조이스틱. HUD에 좌표 X/Y와 범례 표시.

## 4. 앞으로도 유지할 설계 원칙

이 단계에서 확정했고, 이후 단계에서도 바꾸지 않을 결정들입니다.

- **한 행성(아스마라)만 완결시킨다.** 다른 행성으로의 이동, 행성 간 허브는 만들지 않습니다.
- **MMO 요소는 전부 제외한다.** 서버, 다중접속, 파티, 채팅 없음. 오프라인 싱글플레이어.
- **시야 제한은 안개가 아니라 구체 투영 수식으로 만든다.** V3에서 한 번 폐기한 방향으로 돌아가지 않습니다.
- **카메라는 북쪽 고정.** 플레이어를 따라가되 회전하지 않습니다. 이후 미니맵 설계도 이 전제 위에서 단순해집니다.

## 7. 이 단계에서 남긴 과제

1단계를 끝내고 나서 드러난 문제가 하나 있습니다.

> **공들여 만든 "지평선 시야 제한"이 지금은 비용만 있고 보상이 없다.**
> 걸어가서 새 지역을 봐도 돌아서면 사라지고, 아무 기록도 남지 않는다.
> 게다가 행성의 71%는 지금 갈 이유가 없다 — 어디를 가도 풍경이 같기 때문에.

이 문제를 푸는 것이 **로드맵 2**의 과제입니다.
